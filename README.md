# Ningbo_Exposure_Simulation_HumanVehicleFlow
# 宁波市10m人居碳、热暴露模拟系统
耦合“人-车-物”活动流的城市复杂建成环境仿真代码库
项目归属：耦合人-车-物活动流的人居环境场景融合模拟技术

## 研究内容
1. 空间句法二维拓扑指标、三维可视特征计算
2. 基于VSP/MOVES出租车路网碳、热排放估算
3. ST-GCN时空图卷积路网逐时碳排放预测 + 多策略融合外推
4. XGBoost城市热岛强度模拟与SHAP驱动因子解析
5. KDE高斯核密度10m分辨率逐小时碳暴露模拟
6. 多情景建筑权重碳暴露、人口加权热岛暴露计算
7. 模拟结果尺度转换验证与可视化

## 核心模型精度指标
- ST-GCN路网碳排放预测：$R^2=0.9071$，RMSE=0.3080，MAE=0.2357
- XGBoost 10m热岛模拟分区验证：$R^2=0.687$，RMSE=3.212，Bias=-0.021
